# 进销存 Cloudflare 版 —— 验收清单

**地址**：https://inventory-b4k.pages.dev
**账号**：`admin` / 你自己改过的密码
**建议**：用**电脑浏览器**验收（本项目**未做手机端适配**，手机上表格会很难用）

清单里给了一套**具体数字**，每步都有期望值 —— 这样验收是"对数字"而不是"看着差不多"。

---

## ⚠️ 三个已知情况（不是 bug，别误判）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 商品**上传图片**报错 | Workers 没有文件系统，必须用 R2；你的账号**未启用 R2** | 图片地址填**外链 URL**，或留空 |
| 手机打开很挤、横向滚动 | 本项目是桌面端管理后台，**没做响应式** | 用电脑验收；手机版是下一个独立任务 |
| 数据库是空的，只有默认仓库 | 刚上线，没有历史数据 | 按下文**从基础数据开始建** |

## 第 2 步：采购全流程（**核心：价内税**）

### 2.1 采购管理 → 采购订单 → 新增

| 字段 | 填 |
|---|---|
| 供应商 | 测试供应商A |
| 商品 | 测试商品A，数量 **10**，单价 **10.5**，税率 **13** |
| 运费 | **5** |

- [ ] 保存成功，单号形如 `PO202609300001`
- [ ] 状态 = **草稿**
- [ ] **整单合计 = 110.00**（明细 10×10.5 = 105，+ 运费 5）
- [ ] 内含税额 ≈ **12.08**（105 − 105÷1.13）
- [ ] 列表页「商品名称」列显示 **测试商品A**（不是空白）

### 2.2 审核

- [ ] 点审核 → 状态变**已审核**
- [ ] 再点一次审核 → 应提示状态不正确

### 2.3 分批收货

- [ ] 先收 **6** → 提示"本次入库 6"，状态变 **部分收货**
- [ ] 库存查询里该商品数量 = **6**
- [ ] 再收 **10** → 应提示**「本次收货 10 超过待收数量 4」**
- [ ] 再收 **4** → 状态变 **已收货**，库存 = **10**

> 关键点：**超收必须被拦住**，且库存不能多算。

## 第 3 步：销售全流程（**核心：库存不足保护**）

### 3.1 销售订单 → 新增

| 字段 | 填 |
|---|---|
| 客户 | 测试客户A |
| 商品 | 测试商品A，数量 **4**，单价 **20** |
| 运费 | 0 |

- [ ] 单号形如 `SO202609300001`，合计 = **80.00**
- [ ] 审核 → 状态**已审核**

### 3.2 发货

- [ ] 发货 **4** → 状态**已发货**，库存 = **6**:（10 − 4）

### 3.3 库存不足保护（重要）

- [ ] 再建一张销售单，数量填 **100**，审核后发货
- [ ] 应提示**「商品#N 库存不足（现有 6）」**
- [ ] 发货失败后回库存查询 → **仍是 6**（失败不能改动库存）
- [ ] 把这张大单**作废**后可以删除

## 第 4 步：退货（**核心：必须关联原单**）

### 4.1 销售退货

- [ ] 销售退货 → 新增 → 选**来源销售单**（第 3 步那张 `SO...`）
- [ ] 系统自动带出：已发 4、已退 0、**可退 4**、原成交价 20
- [ ] 不选来源单直接保存 → 应提示**「请先选择来源销售单，退货必须关联原单」**
- [ ] 数量填 **99** → 应提示**「可退数量仅 4，本次退货 99 超出」**
- [ ] 改成 **2** → 保存成功，单号 `SR...`
- [ ] 审核 → 入库 → 状态变**已退货**
- [ ] 回销售订单看原单 → 状态应变 **部分退货**
- [ ] 库存 = **8**（6 + 2）

### 4.2 采购退货

- [ ] 采购退货 → 新增 → 选来源采购单（第 2 步那个 `PO...`）
- [ ] 可退数量应显示 **10**
- [ ] 退 **3** → 审核 → 出库
- [ ] 原采购单状态变**部分退货**
- [ ] 库存 = **5**（8 − 3）

## 第 5 步：收付款（**核心：四象限凭证**）

财务管理 → 收付款 → 新增，四种各建一笔：

| 类型 | 对象类型 | 往来单位 | 金额 | 应显示的凭证 |
|---|---|---|---|---|
| **收款** | 客户 | 测试客户A | 100 | 借 **银行存款** / 贷 **应收账款** |
| **收款** | 供应商 | 测试供应商A | 50 | 借 **银行存款** / 贷 **应付账款** |
| **付款** | 供应商 | 测试供应商A | 80 | 借 **应付账款** / 贷 **银行存款** |
| **付款** | 客户 | 测试客户A | 30 | 借 **应收账款** / 贷 **银行存款** |

- [ ] 四笔都成功
- [ ] 凭证号形如 **`记-2026-09-0001`**（按会计期间连号）
- [ ] 摘要形如「收测试客户A货款」「付测试供应商A货款」
- [ ] 把支付方式改成**现金**再建一笔 → 借方应变 **库存现金**
- [ ] 编辑其中一笔改金额 → 保存后**凭证号不变**，摘要/借贷按新内容重算
- [ ] 删除一笔 → 成功；**再删一次 → 提示记录不存在**

## 出问题了怎么办

### 想从头再来

```bash
# 清空业务数据（保留账号/角色/权限/仓库）
wrangler d1 execute inventory --file=cf/reset-business-data.sql --remote
```

### 忘了 admin 密码

```bash
# 重置为 Aa123456!
wrangler d1 execute inventory --remote --command "UPDATE users SET password_hash='<盐:哈希>' WHERE username='admin'"
```

（哈希需按 `salt:sha256(salt+密码)` 生成；也可直接找我把命令补全。）

### 页面报错看不懂

打开浏览器 **F12 → Console/Network**，把红色请求的 URL 和响应贴给我。

| 项 | 如果没修会怎样 |
|---|---|
| 结束日期选「今天」能查到今天的数据 | 原版会返回 **0**，报表看着像没数据 |
